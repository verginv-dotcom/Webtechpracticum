Objectives

  • To create an industry-specific image gallery using CSS Grid, with responsive columns, consistent image dimensions, and meaningful captions. The gallery displays logistics, transportation, warehousing, shipping, and delivery services in an attractive and user-friendly layout.
  • To develop an industry-oriented responsive webpage that adapts to desktop, tablet, and mobile screen sizes using CSS media queries.
  • To add meaningful animations that respond to user interactions such as button clicks, information cards, notifications, and opening or closing content sections.
  • To develop dynamic webpage interactions that add, modify, display and remove industry-specific information using DOM manipulation without reloading the webpage.
  • To develop an industry-specific booking form with appropriate input constraints and validation, showing clear error messages for invalid inputs and a success message when the form is submitted successfully.
  • To develop an API-integrated webpage that retrieves industry-specific information from an endpoint and dynamically displays the JSON data, with loading indicators and error handling.
  • To develop an industry-specific task manager supporting Create, Read, Update and Delete (CRUD) operations, with task data stored in Local Storage so it persists after the page is refreshed.
